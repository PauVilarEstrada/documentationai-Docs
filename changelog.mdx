## Overview

This starter-kit changelog helps you track recent releases, improvements, and fixes in one place. Use it as a template for Pau Vilar or adapt it for any project documentation site.

You can use the entries below to summarize what changed, why it changed, and what readers should do next. Keep the language short, specific, and easy to scan.

<Callout kind="tip">

Treat this page as the single source of truth for release history. Add new entries at the top, keep older entries below, and link related guides when a change affects usage.

</Callout>

## How to write a strong entry

<Steps>
  <Step title="Summarize the release" icon="book-open">

Write one short paragraph that explains what changed and why it matters. Keep it focused on the user impact, not internal implementation details.

  </Step>
  <Step title="Group the changes" icon="settings">

Split the release into clear sections such as New Features, Improvements, Bug Fixes, Behavior Changes, and Deprecated Items.

  </Step>
  <Step title="Add examples" icon="code">

Include concrete details when something changed in a workflow, API response, or UI behavior so readers know what to expect.

  </Step>
  <Step title="Link the next action" icon="arrow-right">

End with a short note that points readers to the next doc page, migration step, or configuration update.

  </Step>
</Steps>

## Release note patterns

<Tabs>
  <Tab title="Feature release" icon="zap">

Use this pattern when you ship something new that users can try right away.

```markdown
### New Features

- Added bulk import for project notes.
- Added a dashboard card for recent activity.
```

  </Tab>
  <Tab title="Fix release" icon="x-circle">

Use this pattern when you mainly ship corrections and reliability improvements.

```markdown
### Bug Fixes

- Fixed an issue where saved filters reset after refresh.
- Resolved a layout shift in the sidebar on smaller screens.
```

  </Tab>
  <Tab title="Behavior change" icon="shield">

Use this pattern when a workflow changes but the feature still exists.

```markdown
### Behavior Changes

- Exported files now default to UTF-8 encoding.
- Search results now sort by relevance first, then by recency.
```

  </Tab>
</Tabs>
