---
title: Cannot Access Documentation
description: Fix issues accessing your docs.
---

## Symptoms

- Page won't load
- 403 or 404 errors

## Causes

- Incorrect URL
- Project permissions missing

## Solution

<Steps>
  <Step title="Check the URL">
    Make sure the URL matches your project or document name exactly.
  </Step>
  <Step title="Login">
    Log in with correct credentials to access private docs.
  </Step>
  <Step title="Verify Permissions">
    Ask your admin to grant you access if needed.
  </Step>
</Steps>
