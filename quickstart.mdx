## Overview

## Setup

Follow these steps to install the project and start the local development server.

<Steps>
  <Step title="Install dependencies" icon="download">
    Run the package manager command that matches your team standard.

    ````bash
    npm install
    ````

    If your team uses a different lockfile, you can swap in the equivalent command without changing the rest of the workflow.
  </Step>
  <Step title="Create your environment file" icon="settings">
    Copy your example variables into a local file and adjust the values for your machine.

    ````bash
    cp .env.example .env.local
    ````

    Use placeholders such as `YOUR_API_KEY` or `YOUR_TOKEN` while you are testing locally.
  </Step>
  <Step title="Start the development server" icon="play-circle">
    Launch the app and open it in your browser.

    ````bash
    npm run dev
    ````

    After the server starts, open `http://localhost:3000` in your browser.
  </Step>
</Steps>

## First run

Once the app is running, verify the first screen and confirm that your configuration is loaded.

<CodeGroup tabs="TypeScript,Bash,JSON">
  ```typescript

    apiBaseUrl: string;

  const config: AppConfig = {
    projectName: "Pau Vilar",
    apiBaseUrl: "https://api.example.com"

  console.log(`Starting ${config.projectName} with ${config.apiBaseUrl}`);
  ```

  ```bash
  curl https://api.example.com/health
  ```

  ```json
  {
    "status": "ok",
  ```

</CodeGroup>

If the app responds as expected, you have completed the first run. You can now adapt the sample config to your own project name, routes, and data source.

## Common setup issues

A few issues appear often during the first setup. Most of them are easy to fix once you know where to look.

<ExpandableGroup>
  <Expandable title="The app does not start" default-open="true">
    
    Check that dependencies installed correctly and that no other service is using the same port. If needed, stop the conflicting process and restart the server.
    
  </Expandable>
  <Expandable title="Environment variables are missing" default-open="false">
    
    Verify that `.env.local` exists and that the variable names match the ones expected by your app. Keep values in plain text only for local development.
    
  </Expandable>
  <Expandable title="The build fails" default-open="false">
    
    Look for TypeScript errors, missing imports, or unsupported package versions. Run the build command again after you fix the reported issue.
    
  </Expandable>
</ExpandableGroup>
