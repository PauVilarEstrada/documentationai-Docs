<CodeGroup tabs="JavaScript,Python,cURL">
  ```javascript
  const response = await fetch("https://api.example.com/workflows", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "Authorization": "Bearer YOUR_API_TOKEN"
    },
    body: JSON.stringify({
      name: "Monthly report",
      source: "sales",
      refresh: "daily"
    })
  });

  const data = await response.json();
  console.log(data.status);
  ```

  ```python
  import requests

  response = requests.post(
      "https://api.example.com/workflows",
      headers={
          "Content-Type": "application/json",
          "Authorization": "Bearer YOUR_API_TOKEN"
      },
      json={
          "name": "Monthly report",
          "source": "sales",
          "refresh": "daily"
      }
  )

  print(response.json()["status"])
  ```

  ```bash
  curl -X POST "https://api.example.com/workflows" \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer YOUR_API_TOKEN" \
    -d '{
      "name": "Monthly report",
      "source": "sales",
      "refresh": "daily"
    }'
  ```
</CodeGroup>

The example above shows a realistic workflow payload you can adapt. You can replace the endpoint, fields, and authentication scheme to match your own implementation while keeping the same pattern.
